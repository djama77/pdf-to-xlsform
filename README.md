# PDF to XLSForm

Convert questionnaires from PDF, DOCX and TXT into XLSForm workbooks for KoboToolbox and KoboCollect.

This repository is being initialized with a local-first Python engine. Generated forms must be reviewed before field deployment; complex skip logic, repeats, matrices and scanned-PDF OCR are not fully reconstructed automatically.

## Status

Early development. See the package documentation and tests as they are added.
